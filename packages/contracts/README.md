# Lumini — `packages/contracts`

Tipos e schemas TypeScript dos payloads de sincronização entre os clientes (app mobile e web) e a API — o contrato exato do que é enviado no push e recebido no pull.

## Escopo

Schema JSON de upload de propostas, clientes, instalações e solicitações de upgrade; schema de download do catálogo, preços, parâmetros comerciais e contador do plano. Usado pela API apenas para validação de payload (a API não calcula, apenas persiste).
