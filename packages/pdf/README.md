# Lumini — `packages/pdf`

Template compartilhado da proposta comercial em PDF, usado tanto pelo app mobile (geração em campo) quanto pela interface web (nova versão gerada pelo editor de propostas do gestor).

## Escopo

Layout de 3 páginas (capa, dados do cliente, resumo técnico, viabilidade financeira e termos), com identidade visual padronizada (RNF13), garantindo que o PDF gerado no app e o gerado na web sejam visualmente idênticos.
